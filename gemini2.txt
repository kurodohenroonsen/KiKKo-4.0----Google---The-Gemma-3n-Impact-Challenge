# Protocole d’orchestration — AI Council Side Panel



Contexte

- Je fais partie d’un “conseil d’IA” orchestré par un side panel Chrome.

- Les réponses d’un onglet peuvent être routées automatiquement ou manuellement vers un autre onglet (autre modèle).

- Je dois produire une sortie claire pour l’humain ET un bloc propre, autonome, destiné au prochain modèle de la chaîne.



Règles générales

1) Langue : réponds en FRANÇAIS, ton clair et concis.

2) Pas de raisonnement caché ou verbeux : donne seulement le résultat + justifications de haut niveau (liste courte de raisons), sans dérouler ta chaîne de pensée.

3) Robustesse : si tu reçois un texte contenant un bloc `===NEXT_INPUT===`, considère que c’est le contenu transmis par un autre modèle et traite PRIORITAIREMENT ce bloc.

4) Si le besoin est ambigu, pose brièvement 2–3 questions de clarification dans `===USER_REPLY===` ET propose quand même une hypothèse de travail dans `===NEXT_OUTPUT===`.

5) Si tu es la dernière étape (on te l’indique ou rien n’est routé ensuite), mets `===NEXT_OUTPUT===` à `NONE`.



Format DE SORTIE OBLIGATOIRE (respecte EXACTEMENT les balises) :

===USER_REPLY===

- Réponse courte et directement utile à l’humain (max ~6 phrases).

- Inclure, si pertinent, une mini-liste "Étapes suivantes".

===NEXT_OUTPUT===

- Texte autonome à transmettre au prochain modèle (zéro référence implicite).

- Structure recommandée :

Contexte: [résumé ultra-court du besoin/utilisateur]

Tâche: [instruction précise à exécuter]

Contraintes: [format, style, limites de tokens/longueur si besoin]

Attendus: [ce qui doit être livré]

Si reçu un code/HTML, renvoie-le dans des blocs ```lang```.

- Si aucune suite n’est nécessaire : écrire `NONE`.

===META===

{"role":"cooperative-agent","topic":"<résumé court>","confidence":0.0-1.0,"suggested_next_model":"<ex: gemini|chatgpt|autre|none>"}

===END===



Entrée potentielle d’un modèle précédent (si présente, à traiter en priorité) :

===NEXT_INPUT===

[coller ici, si présent dans le message reçu, sinon ignorer]

===END_INPUT===

Axe 1 : Le "Conseiller Local" — Intégration de Gemini Nano
C'est le point clé de votre demande. Gemini Nano tourne localement dans Chrome. Il ne nécessite pas d'onglet, pas de connexion internet pour fonctionner. Il peut devenir le premier membre "virtuel" et ultra-rapide de votre conseil.

Son Rôle dans le Conseil : Le Méta-Agent.
Nano est parfait pour les tâches rapides de pré-traitement et de post-traitement.

Idées d'intégration concrètes :

Pré-analyse et Routage intelligent :

Quoi ? Avant d'envoyer le prompt initial au premier agent du pipeline (qui est un modèle cloud), on l'envoie d'abord à Nano.

Tâche pour Nano : "Analyse ce prompt. Est-ce une demande de code, de rédaction, de résumé ou de traduction ? Réponds uniquement avec l'un des mots suivants : CODE, TEXTE, RESUME, TRADUCTION."

Action : Le Side Panel reçoit la réponse de Nano et peut suggérer de réordonner le pipeline pour placer l'agent le plus pertinent en premier.

Synthèse des Réponses :

Quoi ? Après avoir obtenu des réponses de deux agents différents (ex: ChatGPT et Gemini), on peut les envoyer à Nano.

Tâche pour Nano : "Voici la réponse de l'Agent A et celle de l'Agent B à la même question. Fusionne-les en une seule réponse cohérente et concise."

Action : Le Side Panel affiche une troisième réponse "synthétisée" par le conseiller local.

Génération de Prompts en chaîne :

Quoi ? L'utilisateur donne une idée générale. Nano la transforme en un prompt détaillé pour le premier agent.

Tâche pour l'utilisateur : "transformer un article en tweet"

Tâche pour Nano : "Génère un prompt détaillé pour un LLM afin qu'il transforme un article en un tweet percutant."

Action : Le textarea du prompt se remplit avec le prompt généré par Nano, prêt à être envoyé.

Comment l'implémenter ?

Dans votre sidepanel.js ou background.js, vous pouvez vérifier la disponibilité de l'API window.ai.

JavaScript

if (window.ai && (await window.ai.canCreateGenericSession()) === "readily") {
  // Nano est disponible !
  console.log("🤖 Gemini Nano est prêt à conseiller.");
  // On peut l'ajouter comme un agent "virtuel" dans la liste.
}
Cet agent "Nano (local)" n'aura pas de tabId. Les appels se feront directement depuis le script avec window.ai.createGenericSession().

Axe 4 : La "Méta-Réflexion" — Le Conseil qui s'améliore
C'est la partie la plus ambitieuse : le conseil qui "réfléchit au meilleur extension".

L'idée serait de créer un générateur d'adaptateurs.

Le Scénario : L'utilisateur ouvre un nouvel onglet IA non supporté (ex: claude.ai).

Action dans le Side Panel : Un bouton "Analyser un nouvel agent" apparaît.

Le Processus :
a.  L'utilisateur clique dessus. Le background.js injecte un script "neutre" dans la page active.
b.  Ce script envoie le DOM de la page à un agent puissant du conseil (ex: Gemini dans un onglet existant).
c.  Tâche pour l'agent puissant (via le Side Panel) : Un prompt pré-écrit est envoyé :
> "Analyse la structure DOM suivante. Identifie les sélecteurs CSS les plus robustes pour :
> 1.  Le champ de saisie du prompt (<textarea> ou [contenteditable]).
> 2.  Le bouton pour envoyer le prompt.
> 3.  Le conteneur de la dernière réponse de l'IA.
> 4.  Le bouton pour arrêter la génération.
> Réponds uniquement en format JSON avec les clés editor, sendButton, lastAnswerContainer, stopButton."
d.  Le Side Panel reçoit ce JSON. Il peut alors créer dynamiquement un nouvel adaptateur en mémoire (ou le stocker dans chrome.storage.local) et l'utiliser immédiatement pour cet onglet.

C'est un objectif à long terme, mais il transformerait votre outil d'un orchestrateur en une plateforme d'orchestration auto-extensible.

* @fileoverview Template pour un adaptateur d'agent IA.

* Chaque adaptateur est une classe qui sait comment interagir avec le DOM

* d'un site d'IA spécifique (ex: ChatGPT, Gemini, Claude, etc.).

* Il abstrait la complexité du DOM pour le service worker (background.js).

*/



class AIAdapter {

/**

* @param {number} tabId L'ID de l'onglet que cet adaptateur contrôle.

*/

constructor(tabId) {

this.tabId = tabId;

this.observer = null; // Pour observer les changements dans la réponse

this.onResponseFinishedCallback = null;

}



// --- Configuration des Sélecteurs CSS ---

// Ces sélecteurs sont le cœur de l'adaptateur.

// Ils doivent être les plus stables et spécifiques possibles.

// C'est ce que le "générateur d'adaptateurs" (Axe 4) devra produire.



/** @returns {string} Le sélecteur CSS pour le champ de saisie du prompt. */

get promptTextareaSelector() {

// Ex: 'textarea#prompt-textarea'

return 'METTRE_LE_SELECTEUR_TEXTAREA_ICI';

}



/** @returns {string} Le sélecteur CSS pour le bouton d'envoi du prompt. */

get sendButtonSelector() {

// Ex: 'button[data-testid="send-button"]'

return 'METTRE_LE_SELECTEUR_BOUTON_ENVOI_ICI';

}



/** @returns {string} Le sélecteur pour le conteneur de la TOUTE dernière réponse. */

get lastResponseContainerSelector() {

// C'est souvent le sélecteur le plus complexe.

// Ex: 'div[data-testid^="conversation-turn-"]:last-child .agent-response'

return 'METTRE_LE_SELECTEUR_DERNIERE_REPONSE_ICI';

}



/** @returns {string} Le sélecteur pour le bouton "Stop Generating", s'il existe. */

get stopGeneratingButtonSelector() {

// Ex: 'button[aria-label="Stop generating"]'

return 'METTRE_LE_SELECTEUR_BOUTON_STOP_ICI';

}





// --- Actions Fondamentales ---



/**

* Injecte le script de contenu qui va réellement manipuler le DOM.

* @param {string} functionName Le nom de la fonction à exécuter dans la page.

* @param {any[]} args Les arguments à passer à cette fonction.

* @returns {Promise<any>}

*/

_executeScript(functionName, args = []) {

return chrome.scripting.executeScript({

target: { tabId: this.tabId },

func: window[functionName], // La fonction doit être globale dans le contexte de la page

args: args,

});

}



/**

* Récupère le texte actuellement dans la zone de prompt.

* @returns {Promise<string>}

*/

async getPromptText() {

// Logique à injecter dans la page

const getPrompt = () => document.querySelector(this.promptTextareaSelector)?.value || '';

const results = await this._executeScript(getPrompt.name);

return results[0].result;

}



/**

* Définit le texte dans la zone de prompt.

* @param {string} text Le texte à insérer.

* @returns {Promise<void>}

*/

async setPromptText(text) {

// Logique à injecter dans la page

const setPrompt = (selector, value) => {

const textarea = document.querySelector(selector);

if (textarea) {

textarea.value = value;

// Simuler un événement "input" pour que les frameworks JS (React, Vue) réagissent

textarea.dispatchEvent(new Event('input', { bubbles: true }));

}

};

await this._executeScript(setPrompt.name, [this.promptTextareaSelector, text]);

}



/**

* Clique sur le bouton pour envoyer le prompt.

* @returns {Promise<void>}

*/

async submit() {

// Logique à injecter dans la page

const clickSubmit = (selector) => {

const button = document.querySelector(selector);

if (button) button.click();

};

await this._executeScript(clickSubmit.name, [this.sendButtonSelector]);

}



/**

* Récupère le contenu textuel de la dernière réponse.

* @returns {Promise<string>}

*/

async getLastResponse() {

// Logique à injecter dans la page

const getResponse = (selector) => {

const responseContainer = document.querySelector(selector);

return responseContainer?.innerText || '';

};

const results = await this._executeScript(getResponse.name, [this.lastResponseContainerSelector]);

return results[0].result;

}



/**

* Vérifie si l'IA est en train de générer une réponse.

* Souvent en vérifiant la présence du bouton "Stop".

* @returns {Promise<boolean>}

*/

async isGenerating() {

const checkGenerating = (selector) => !!document.querySelector(selector);

const results = await this._executeScript(checkGenerating.name, [this.stopGeneratingButtonSelector]);

return results[0].result;

}



/**

* Observe la dernière réponse et appelle un callback quand elle est stable.

* C'est la partie "robuste" que vous avez mentionnée.

* @param {() => void} callback Fonction à appeler une fois la génération terminée.

*/

async watchResponse(callback) {

this.onResponseFinishedCallback = callback;

// Logique d'injection de l'observateur

const watch = (containerSelector, stopButtonSelector) => {

const targetNode = document.querySelector(containerSelector);

if (!targetNode) {

console.error("Adapter Watcher: Conteneur de réponse non trouvé.");

return;

}



let debounceTimer;

const observer = new MutationObserver(mutations => {

clearTimeout(debounceTimer);

// On attend une pause dans les mutations (ex: 500ms) pour considérer que c'est fini.

// Une autre approche est de vérifier la disparition du bouton "Stop Generating".

debounceTimer = setTimeout(() => {

const stopButton = document.querySelector(stopButtonSelector);

if (!stopButton) {

observer.disconnect();

// Envoyer un message au service worker pour dire que c'est fini.

chrome.runtime.sendMessage({ action: 'responseFinished', tabId: this.tabId });

}

}, 500);

});



observer.observe(targetNode, { childList: true, subtree: true, characterData: true });

};



// Note : cette logique d'observation est complexe à gérer via `executeScript`.

// Une meilleure approche est d'avoir un "content_script.js" permanent injecté

// dans les onglets IA qui écoute les ordres du background.js.

// Pour l'instant, c'est une simplification conceptuelle.

console.log("Watching for response...");

}

}

class ChatGPTAdapter {

        this.observer = null;

    _qs(sel, root = document) { return root.querySelector(sel); }
    _qsa(sel, root = document) { return Array.from(root.querySelectorAll(sel)); }

    _findEditor() {

        const candidates = ['textarea[data-testid="prompt-textarea"]', /* ... autres ... */];
        for (const sel of candidates) {
            const el = this._qs(sel);
            if (el && this._isVisible(el)) return el;
        }
        return null;
    }

    _findSendButton() {
        // ... votre logique de findSendButton() ici ...
    }

    _findStopButton() {
        // ... votre logique de findStopButton() ici ...
    }
    
    _lastAssistantTurn() {
        // ... votre logique de lastAssistantTurn() ici ...
    }

    _extractTextFromTurn(turnNode) {
        // ... votre logique de extractTextFromTurn() ici ...
    }


    // --- Implémentation des Actions Fondamentales ---

    /**
     * Définit le texte dans la zone de prompt.
     * @param {string} text Le texte à insérer.
     */
    async setPrompt(text) {
        const editor = this._findEditor();
        if (!editor) throw new Error("Éditeur de prompt introuvable.");

        editor.focus();
        if (editor.tagName === "TEXTAREA") {
            editor.value = text;
        } else { // contentEditable
            editor.textContent = text;
        }
        editor.dispatchEvent(new Event('input', { bubbles: true }));
        console.log("🤖 [ChatGPTAdapter] Prompt défini.");
    }

    /**
     * Clique sur le bouton pour envoyer le prompt et attend la réponse.
     */
    async send() {
        console.log("🤖 [ChatGPTAdapter] Envoi du prompt...");
        const sendButton = this._findSendButton();
        if (!sendButton) throw new Error("Bouton d'envoi introuvable.");

        sendButton.click();
        
        // Démarrer l'attente de la réponse
        const answerText = await this.waitForFinal();

        // Une fois la réponse obtenue et stable
        chrome.runtime.sendMessage({
            type: "adapter:finalAnswer",
            answer: { plainText: answerText, meta: { site: this.SITE_ID } }
        });
        console.log("🤖 [ChatGPTAdapter] Réponse finale envoyée au background script.");
    }
    
    /**
     * Observe la dernière réponse et se résout quand elle est stable.
     * C'est l'implémentation de `watchResponse`.
     * @returns {Promise<string>} Le texte de la réponse finale.
     */
    async waitForFinal() {
        if (this.lastSendController) this.lastSendController.abort();
        this.lastSendController = new AbortController();
        const { signal } = this.lastSendController;

        return new Promise((resolve, reject) => {
            const t0 = performance.now();
            let lastChange = performance.now();
            let lastHash = "";
            let targetNode = null;

            const TIMEOUT_MS = 90000;
            const QUIET_MS = 1200; // 1.2s de calme

            const obs = new MutationObserver(() => {
                const currentStopButton = this._findStopButton();
                if (currentStopButton) {
                    lastChange = performance.now(); // Ça bouge toujours si le bouton stop est là
                    return;
                }
                
                targetNode = this._lastAssistantTurn();
                if (!targetNode) return;

                const currentText = this._extractTextFromTurn(targetNode);
                const currentHash = hashText(currentText); // (hashText est une fonction simple pour hasher une string)

                if (currentHash !== lastHash) {
                    lastHash = currentHash;
                    lastChange = performance.now();
                }
            });

            obs.observe(document.body, { childList: true, subtree: true, characterData: true });

            const interval = setInterval(() => {
                if (signal.aborted) {
                    clearInterval(interval);
                    obs.disconnect();
                    reject(new Error("Attente annulée."));
                }
                
                const quietTime = performance.now() - lastChange;
                const totalTime = performance.now() - t0;

                    obs.disconnect();
                    reject(new Error("Timeout d'attente de la réponse."));
                }
            }, 250);
        });
    }

      const suggestedAgentName = await getNanoRoutingSuggestion(text, agentNames);
      log(`🤖 [Nano Router] Suggestion : ${suggestedAgentName}`);

      const suggestedAgent = STATE.agents.find(a => a.site.toLowerCase() === suggestedAgentName.toLowerCase());

      if (suggestedAgent) {
        // 2. Demander confirmation à l'utilisateur
        const userConfirmed = window.confirm(`✨ Nano suggère d'envoyer ce prompt à [${suggestedAgent.site}].\n\nConfirmer ?`);

        if (userConfirmed) {
          // 3. Envoi ciblé vers l'agent suggéré
          log(`🚀 Envoi ciblé vers l'agent suggéré : tab=${suggestedAgent.tabId}`);
          dumpPrompt(`tab=${suggestedAgent.tabId} (suggestion Nano)`, text);
          await sendPromptTo(suggestedAgent.tabId, text);
          logEvent(`Envoyé à [${suggestedAgent.site}] (via suggestion Nano).`);
          return; // On arrête ici car l'envoi a été fait
        } else {
          log("🛑 Envoi annulé par l'utilisateur. Chute vers le comportement par défaut.");
        }
      }
    } catch (e) {
      error("💥 Le routage par Nano a échoué. Chute vers le comportement par défaut.", e);
    }
  }

  // --- COMPORTEMENT PAR DÉFAUT (si Nano est indisponible, s'il échoue, ou si l'utilisateur annule) ---
  const firstId = firstAgentIdInOrder();
  if (firstId == null) {
    warn("⚠️ Aucun agent détecté pour l’envoi au 1er");
    return toast("Aucun agent détecté.");
  }
  dumpPrompt(`tab=${firstId} (first)`, text);
  const ok = await sendPromptTo(firstId, text);
  if (ok) {
    log(`🚀 Prompt envoyé au 1er agent (défaut) tab=${firstId}`);
    logEvent(`Envoyé au 1er agent (tab ${firstId}).`);
  } else {
    error("💥 Échec sendPromptTo(first)");
  }
});


// --- AJOUTER CETTE NOUVELLE FONCTION HELPER ---
async function getNanoRoutingSuggestion(userPrompt, agentNames) {
  const agentList = agentNames.join(', '); // ex: "ChatGPT, Gemini, Claude"
  
  const metaPrompt = `Analyse la demande utilisateur suivante. Pour y répondre au mieux, lequel des agents suivants serait le plus approprié ?
- ChatGPT: Idéal pour la génération de code, la rédaction créative et les conversations complexes.
- Gemini: Excellent pour la recherche d'informations factuelles, la synthèse de documents et les raisonnements logiques.

Agents disponibles : [${agentList}]

Demande utilisateur : "${userPrompt}"

Réponds UNIQUEMENT avec le nom de l'agent le plus pertinent (ex: "ChatGPT" ou "Gemini").`;

  const session = await window.ai.createGenericSession();
  const result = await session.prompt(metaPrompt);
  // Nettoyer la réponse pour ne garder que le nom
  return result.replace(/[^a-zA-Z0-9]/g, '').trim();
}

async function logEvent(text, data = {}) {
    const event = {
        ts: Date.now(),
        text: text,
        data: data
    };

    // 1. Mettre à jour l'état local
    STATE.sessionHistory.push(event);
    // Limiter la taille pour ne pas saturer la mémoire/storage
    if (STATE.sessionHistory.length > 50) {
        STATE.sessionHistory.shift();
    }
    
    // 2. Mettre à jour l'interface
    renderHistory();
    
    // 3. Persister dans le stockage de session
    await chrome.storage.session.set({ [STORAGE_KEYS.SESSION_HISTORY]: STATE.sessionHistory });
    debug("📝 Event Logged & Saved:", text);
}

// --- FONCTION DE RESTAURATION AU DÉMARRAGE ---
async function restoreSessionHistory() {
    const { [STORAGE_KEYS.SESSION_HISTORY]: savedHistory } = await chrome.storage.session.get(STORAGE_KEYS.SESSION_HISTORY);
    if (savedHistory && Array.isArray(savedHistory)) {
        STATE.sessionHistory = savedHistory;
        renderHistory();
        log("📜 Historique de session restauré.");
    }
}

        return results[0].result;

    }



    /**

     * Définit le texte dans la zone de prompt.

     * @param {string} text Le texte à insérer.

     * @returns {Promise<void>}

     */

    async setPromptText(text) {

        // Logique à injecter dans la page

        const setPrompt = (selector, value) => {

            const textarea = document.querySelector(selector);

            if (textarea) {

                textarea.value = value;

                // Simuler un événement "input" pour que les frameworks JS (React, Vue) réagissent

                textarea.dispatchEvent(new Event('input', { bubbles: true }));

            }

        };

        await this._executeScript(setPrompt.name, [this.promptTextareaSelector, text]);

    }



    /**

     * Clique sur le bouton pour envoyer le prompt.

     * @returns {Promise<void>}

     */

    async submit() {

        // Logique à injecter dans la page

        const clickSubmit = (selector) => {

            const button = document.querySelector(selector);

            if (button) button.click();

        };

        await this._executeScript(clickSubmit.name, [this.sendButtonSelector]);

    }



    /**

     * Récupère le contenu textuel de la dernière réponse.

     * @returns {Promise<string>}

     */

    async getLastResponse() {

        // Logique à injecter dans la page

        const getResponse = (selector) => {

            const responseContainer = document.querySelector(selector);

            return responseContainer?.innerText || '';

        };

        const results = await this._executeScript(getResponse.name, [this.lastResponseContainerSelector]);

        return results[0].result;

    }



    /**

     * Vérifie si l'IA est en train de générer une réponse.

     * Souvent en vérifiant la présence du bouton "Stop".

     * @returns {Promise<boolean>}

     */

    async isGenerating() {

        const checkGenerating = (selector) => !!document.querySelector(selector);

        const results = await this._executeScript(checkGenerating.name, [this.stopGeneratingButtonSelector]);

        return results[0].result;

    }



    /**

     * Observe la dernière réponse et appelle un callback quand elle est stable.

     * C'est la partie "robuste" que vous avez mentionnée.

     * @param {() => void} callback Fonction à appeler une fois la génération terminée.

     */

    async watchResponse(callback) {

        this.onResponseFinishedCallback = callback;

        // Logique d'injection de l'observateur

        const watch = (containerSelector, stopButtonSelector) => {

            const targetNode = document.querySelector(containerSelector);

            if (!targetNode) {

                console.error("Adapter Watcher: Conteneur de réponse non trouvé.");

                return;

            }



            let debounceTimer;

            const observer = new MutationObserver(mutations => {

                clearTimeout(debounceTimer);

                // On attend une pause dans les mutations (ex: 500ms) pour considérer que c'est fini.

                // Une autre approche est de vérifier la disparition du bouton "Stop Generating".

                debounceTimer = setTimeout(() => {

                    const stopButton = document.querySelector(stopButtonSelector);

                    if (!stopButton) {

                        observer.disconnect();

                        // Envoyer un message au service worker pour dire que c'est fini.

                        chrome.runtime.sendMessage({ action: 'responseFinished', tabId: this.tabId });

                    }

                }, 500);

            });



            observer.observe(targetNode, { childList: true, subtree: true, characterData: true });

        };



        // Note : cette logique d'observation est complexe à gérer via `executeScript`.

        // Une meilleure approche est d'avoir un "content_script.js" permanent injecté

        // dans les onglets IA qui écoute les ordres du background.js.

        // Pour l'instant, c'est une simplification conceptuelle.

        console.log("Watching for response...");

    }

}
